Component documentation
=======================

rocPyDecode contains two independently buildable and installable components.
Each component owns the documentation required to understand and use it:

* `videoDecode documentation <https://github.com/ROCm/rocPyDecode/tree/develop/videoDecode/docs>`_
  covers the video API, decoder and demuxer classes, memory types, supported
  codecs, installation, and samples.
* `jpegDecode documentation <https://github.com/ROCm/rocPyDecode/tree/develop/jpegDecode/docs>`_
  covers the JPEG API, installation, and samples.

The umbrella documentation describes combined configuration and installation.
The component documentation remains colocated with its implementation so it
can move with that component if it is extracted into a separate repository.
